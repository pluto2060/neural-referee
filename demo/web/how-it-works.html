3Referee
Compares against a reference run with the golden weights, without re-running everything
3a. Hash-chain
bisection
Each step extends a running hash hi = H(hi-1, ti). Compare with the reference, halve the range each time, and find the first step that differs.
about log2(N) comparisons: 3,107 steps -> 12 comparisons -> step 1,542
3b. Recheck one
step by sublayer
Recompute only that step with the golden weights and compare the 16 sublayer outputs in order -> first sublayer that disagrees (here L2.attn). About 0.03% of the run is recomputed.
3c. Scan earlier
positions
If that step computes correctly, the fault came in earlier through attention memory -> recheck earlier positions with the same arithmetic to find where it started (needed in 7 of 40 cases).
PASS every step matches -> the final hash is the receipt
FAIL first wrong step + faulty sublayer (+ origin)

The principle in three lines
1. Chain the execution into hashes, and "where did it diverge" takes log N comparisons.
2. A computer in weights is deterministic, so recomputing one step with golden weights exposes the faulty sublayer.
3. Deliver only answers with a PASS receipt: a fault becomes a re-run or a withheld answer, never a wrong answer.
Numbers: neural-referee/results (baseline_table.json, h_r*.json, agent_stress.json, demo_fault_harmful.json). The bisection follows Verde (2025), applied here to a neural computer for the first time. Measured on one 7-layer transformer-vm.
